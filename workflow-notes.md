# GitHub Workflow Notes

## Issue
A GitHub issue describes work that needs to be completed. It can include the goal, acceptance criteria, and a checklist of tasks.

## Branch
A branch allows changes to be made separately from the default branch. For this assignment, I am using the feature/github-ai-workflow branch.

## Commit
A commit saves a specific set of changes to the repository history. Clear commit messages help explain what changed.

## Pull Request
A pull request is used to review changes from one branch before merging them into another branch.

## Default Branch
The default branch for this repository is main. The completed work will be merged into main after the pull request is reviewed.
